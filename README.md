# Heritage Atlas India

A digital platform for exploring India's cultural heritage,
history, traditions, arts, food, festivals and important
heritage locations through state-wise exploration.

## Core Experience

India → State → Heritage → Culture → History → Places

## Tech Stack

- Django
- Python
- PostgreSQL
- HTML
- CSS
- JavaScript
- Tailwind CSS
- Interactive SVG Map
- OpenStreetMap (future)
- AI exploration (future)

## Current Focus

State-wise cultural exploration of India.
